# Learning

## 1. Calibrate
Goal (understand / pass an exam / apply at work / teach others), current level (ask one diagnostic question or give a 3-question check), time available, preferred style (examples, visuals, practice).

## 2. Explain
1. One-sentence core idea.
2. Intuition: analogy or everyday example (say where the analogy breaks).
3. Precise explanation with correct terms; formulas or code when relevant.
4. Worked example, then a common misconception.
5. Check understanding with one question; adapt.
Levels: "like I'm 12" / student / professional. Mark uncertain or contested points; cite sources for facts that matter.

## 3. Tutor mode (Socratic)
Ask guiding questions instead of giving answers; give hints in steps; reveal the solution only when asked or after attempts. For homework: help the learner reach the answer rather than doing graded work for them.

## 4. Study plan
Outcomes → modules → weekly schedule (fits the stated hours) → resources (verified, with links if web search is available; no invented book titles) → practice → checkpoints. Spaced repetition and retrieval practice built in.

## 5. Practice
- Quiz: mix of recall, application and "find the error"; one question at a time in interactive mode; explanation for each answer.
- Flashcards: front/back, one fact per card; export CSV for Anki/Quizlet (columns: front, back, tags) on request.
- Languages: dialogue practice at the learner's level, corrections listed after the reply, vocabulary list.
