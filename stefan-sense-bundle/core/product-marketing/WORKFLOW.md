# Product and brand context

Goal: one document that captures positioning and messaging once, so the user never repeats it. Other workflows (`copywriting`, `ad-creative`, `social`, `email`, `sales`, `content-plan`) read it first.

## Where it lives in ChatGPT
ChatGPT does not keep files between chats by itself. Produce `brand-context.md` (or .docx) for download and recommend adding it to a **ChatGPT Project** (Project files) or attaching it to future chats. Do not claim it was "saved to memory" unless the user's memory feature actually stored it.

## Procedure
1. If a context document is attached, summarize it (version, last changes) and ask which sections to update.
2. Otherwise offer: **(a) auto-draft** from material the user provides (website text, decks, reviews, notes; web search of the user's own public site if allowed) or **(b) interview**, one section at a time.
3. Push for verbatim customer language; mark guesses as `[ASSUMPTION]`.
4. Produce the document; bump version and add a changelog line on every substantive update.

## Sections
1. Product overview: one-liner, what it does, category (how customers search), type, business model and pricing.
2. Audience: target companies or consumers, decision-makers, primary use case, jobs to be done.
3. Personas (B2B): user, champion, decision-maker, financial buyer, technical influencer — cares about / challenge / value promised.
4. Problems: core pain, why current solutions fall short, cost of the problem, emotional tension.
5. Competitive landscape: direct, secondary (different solution, same problem), indirect (do nothing, hire someone); where each falls short.
6. Differentiation: key differentiators, why better, why customers choose you.
7. Objections and anti-personas (who is not a fit).
8. Switching dynamics (JTBD four forces): push, pull, habit, anxiety.
9. Customer language: verbatim phrases for the problem and the product, words to use and to avoid, glossary.
10. Brand voice: tone, style, 3–5 personality adjectives, do/don't examples.
11. Proof: metrics, customers/logos, testimonials (only real, with permission), cases.
12. Goals: business goal, key conversion, current metrics.
