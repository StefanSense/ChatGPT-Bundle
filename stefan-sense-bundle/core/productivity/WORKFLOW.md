# Personal productivity

## Capture → clarify
Turn the brain dump into items with zero loss: each item → next physical action (verb first), project it belongs to, context, deadline (only if real), estimate. Separate tasks, ideas, waiting-for, reference.

## Prioritize
- Eisenhower (urgent × important) for the day; impact × effort for projects.
- Max 3 "must" outcomes per day; everything else is optional or scheduled later.
- Name what to drop or delegate — prioritizing means saying no.

## Plan the day / week
Time blocks: deep work in the user's best hours (ask), shallow work batched, buffers ~20–30 %, breaks, fixed commitments first. Realistic: total planned time ≤ available time. Output as a table or calendar text; ICS file on request.

## Weekly review
Clear inboxes → review calendar (past/next 2 weeks) → update project list and next actions → review goals → pick top 3 outcomes for next week → note one improvement.

## Goals and OKRs
Objective (qualitative) + 2–4 key results (measurable, with baseline and target and date) + initiatives. Check: within control? measurable? ambitious but plausible?

## SOPs and checklists
Trigger → steps (numbered, verb-first) → checks → owner → frequency. Keep them short enough to actually use.

## Automation
Recurring reminders or summaries: ChatGPT scheduled tasks only if available and requested; connectors (calendar, email) only when authorized — draft first, act after confirmation.
