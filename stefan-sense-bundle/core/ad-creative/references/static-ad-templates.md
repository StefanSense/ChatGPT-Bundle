# Supplement: static ad templates

Short supplement written for the Stefan Sense Bundle (the original reference file was not available).

Rotate real-proof concepts: review card (verified quote), product demonstration, FAQ, feature/benefit,
founder explanation, comparison (verified features), before/after (real data), statistic (source + denominator).
Output: concept ID, audience, placement, angle, headline, body, CTA, asset brief, source evidence and hypothesis.
Avoid fabricating testimonials, competitors, results and account identity.
