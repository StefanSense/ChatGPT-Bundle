# Stefan Sense Bundle 1.1.1

32 основных направления работы и 586 специализированных методик для ChatGPT: тексты, маркетинг, исследования, аналитика, проекты и документы. Автор исходного бандла — M. Stefan Kassem (Stefan Sense); сторонние авторы и лицензии указаны в AUTHORS.md и THIRD_PARTY_NOTICES.md.

## Подключение

1. Загрузить ZIP целиком: ChatGPT → **Plugins → Skills → Create → Upload from your computer**.
2. Дождаться результата проверки ChatGPT и установить/включить навык, если интерфейс это предлагает.
3. В новом чате выбрать навык через `@` или написать: «Используй Stefan Sense Bundle: …».

Доступность Skills и загрузки зависит от аккаунта, продукта и настроек администратора. ZIP не предоставляет платный тариф, внешние API или новые инструменты сам по себе. Если загрузка отмечена Needs Review, следовать интерфейсу проверки; не обходить блокировку.

Для локального Codex: поместить папку `stefan-sense-bundle` в `~/.agents/skills/` (Windows: `%USERPROFILE%\.agents\skills\`) и вызвать `$stefan-sense-bundle`. Если навык ещё не появился, обновить список навыков. Для обычного Project/GPT предпочтительно приложить нужные текстовые WORKFLOW.md; чтение вложенного ZIP и исполнение скриптов не гарантируются без соответствующих инструментов.

## Проверка после подключения

Попросить: «Используй Stefan Sense Bundle, выполни check, selftest и покажи фактические результаты». Для самостоятельного запуска из папки навыка:

```bash
python scripts/sense.py check
python scripts/sense.py selftest
python scripts/sense.py doctor
python scripts/sense.py search "SOC 2"
python scripts/sense.py show humanize-ru
```

`check` проверяет состав, контрольные суммы и синтаксис. `selftest` проверяет основные локальные функции; отсутствующие зависимости обозначаются как пропуски, а не успешные проверки. `doctor <id>` проверяет импорты выбранной методики. Все команды требуют Python 3.10+. Скрипты не устанавливают зависимости автоматически.

Основные текстовые методики читаются без запуска кода. Для файлов нужны python-docx, reportlab, pypdf, openpyxl и python-pptx; для кириллического PDF — доступный TTF-шрифт (или `font_path`). При отсутствии этих библиотек сначала использовать штатные инструменты файлов ChatGPT. Для сторонних помощников зависимости перечислены в manifest.json и проверяются через doctor; сетевые сервисы требуют отдельного доступа.

## Работа

Ставить задачу обычным языком. Навык выбирает `core/<направление>/WORKFLOW.md`. Узкие методики ищутся командой `sense.py search`, читаются через `show`, распаковываются через `extract <id> --dest <новая пустая папка>`. Локальный поиск поддерживает английские ключевые слова и русские алиасы; запросы на других языках ChatGPT сначала переводит в английские ключевые слова.

Перед использованием цифр, норм, цен и лимитов из справочников проверять актуальные первичные источники. Сканер текста — редакторская эвристика, не детектор авторства и не доказательство неизменности смысла. Формулы Excel не пересчитываются openpyxl: пересчитать файл доступным офисным инструментом либо проверить ключевые расчёты отдельно. После создания документов проверять содержимое и рендеринг.

Информация об установке: https://help.openai.com/en/articles/20001066-skills-in-chatgpt и https://learn.chatgpt.com/docs/build-skills (проверено 07.10.2026). Фактический приём ZIP и доступ к внешним сервисам определяются средой пользователя.

## Безопасность экспериментов в 1.1.1

Модуль autoresearch-agent работает в выбранном проекте с пределами времени и числа попыток. Он не делает автоматических коммитов или откатов. Перед запуском проверяются команда и оценочный скрипт; выполнение требует --approve-eval. Прежние config.cfg нужно явно пересоздать через setup. Команды с операторами оболочки замените проверенным отдельным скриптом. Установка зависит от проверки безопасности сервиса; архив не является подтверждением её прохождения.
