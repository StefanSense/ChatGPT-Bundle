# Stefan Sense Bundle — набор навыков для ChatGPT

**Автор:** M. Stefan Kassem (**Stefan Sense**). Навыки разработаны и адаптированы автором на основе открытых
работ Corey Haines, Siqi Chen, Alireza Rezvani, Affaan Mustafa, Anthropic (example skills), Forward Future и
Humanizer-RU — подробно в [AUTHORS.md](AUTHORS.md).
English version: [README.en.md](README.en.md).

Один навык (skill) для ChatGPT, который сам выбирает подходящую методику под задачу: тексты, редактура,
перевод, маркетинг, исследования, проверка фактов, аналитика, решения, проекты, продажи, карьера, обучение,
промпты, код, договоры, визуал и файлы Word/PDF/Excel/PowerPoint.

## Что внутри
| Часть | Что это |
|---|---|
| `SKILL.md` | маршрутизатор и постоянные правила точности (не выдумывать факты, источники, язык пользователя) |
| `core/` — 32 основных навыка | ежедневные задачи; обычные файлы, читаются без распаковки |
| `library/` — 586 специализированных навыков | разработка, маркетинг, руководство, комплаенс, исследования и др.; поиск и распаковка по одному |
| `scripts/` | `sense.py` (поиск/показ/распаковка), `docs.py` (DOCX/PDF/XLSX/PPTX), `text_scan.py` (маркеры RU/EN) |
| `licenses/`, `AUTHORS.md`, `THIRD_PARTY_NOTICES.md` | авторство и лицензии |

Основные навыки: `write`, `edit`, `translate`, `summarize`, `humanize-ru`, `humanize-en`, `email`, `copywriting`,
`ad-creative`, `social`, `product-marketing`, `content-plan`, `seo`, `research`, `fact-check`, `data-analysis`,
`decision`, `strategy`, `meeting`, `project-plan`, `product`, `sales`, `career`, `learn`, `prompt`, `code`,
`contract-review`, `visual`, `productivity`, `documents`, `spreadsheets`, `presentations`.

## Установка

Загружайте **ZIP-архив целиком, не распаковывая** (`Stefan-Sense-Bundle-v1.0.0.zip`). Внутри одна папка
`stefan-sense-bundle/` и ровно один `SKILL.md` — так требует формат навыков OpenAI.

### ChatGPT в браузере (в том числе режим Work)
1. Профиль → **Skills** (Навыки) → **New skill** → **Upload from your computer**.
2. Выберите ZIP. После загрузки включите навык.
3. Навык срабатывает автоматически, когда запрос подходит под описание (`allow_implicit_invocation: true`).
   Вызвать явно: «Используй Stefan Sense Bundle: …» или `$stefan-sense-bundle`.

Ограничения, которые я не могу гарантировать: доступность Skills зависит от тарифа и региона; в Business/Enterprise
администратор рабочего пространства может ограничивать загрузку своих навыков. Названия пунктов меню могут
отличаться — интерфейс OpenAI меняется.

### Приложение ChatGPT для ПК (Windows/macOS)
Загрузка та же: профиль → Skills → загрузить ZIP. По отзывам пользователей навыки веб-версии и приложения
могут не синхронизироваться; если навык не виден в приложении — загрузите его там отдельно.

### Codex (CLI, IDE, приложение)
Распакуйте архив так, чтобы получилось:
- macOS/Linux: `~/.codex/skills/stefan-sense-bundle/SKILL.md`
- Windows: `%USERPROFILE%\.codex\skills\stefan-sense-bundle\SKILL.md`
и перезапустите Codex. Путь к папке навыков может меняться между версиями Codex — сверяйтесь с актуальной
документацией OpenAI.

### Без поддержки навыков
Создайте Project (проект) или свой GPT, приложите ZIP / нужные файлы `core/<навык>/WORKFLOW.md` как файлы
знаний, а текст из раздела «Operating rules» `SKILL.md` вставьте в инструкции.

## Как пользоваться
Просто ставьте задачу: «Сделай КП для клиента…», «Очеловечь этот текст», «Проверь факты в статье»,
«Проанализируй выгрузку продаж», «Сделай презентацию на 10 слайдов».
Узкие задачи: «Найди в библиотеке Stefan Sense навык про GDPR» — модель выполнит
`python scripts/sense.py search "GDPR"` и загрузит нужную методику.

Для скриптов нужно выполнение кода (в ChatGPT — встроенная среда Python). Без него основные навыки всё равно
читаются как текст, а модель обязана сообщить, если методику загрузить не удалось.

## Проверка и пересборка
Исходники и сборка — в репозитории: `python tools/build.py` собирает архив и проверяет лимиты
(один SKILL.md, ≤ 500 файлов, ZIP ≤ 50 МБ, файл ≤ 25 МБ, корректные `name`/`description`);
`python -m pytest -q` — тесты скриптов. Внутри архива: `python scripts/sense.py check`.

## Честные ограничения
- Совместимость проверена по опубликованным требованиям формата и тестами скриптов; фактическую загрузку в ваш
  аккаунт ChatGPT я выполнить не могу — проверьте после загрузки (раздел «Проверка после установки» ниже).
- Цифры, лимиты платформ, цены и нормы закона в справочных материалах библиотеки — непроверенные утверждения
  исходных авторов с неизвестной датой; навыки требуют перепроверки по актуальным источникам.
- Сканер `text_scan.py` — эвристика для редактуры, не детектор ИИ-авторства.
- Юридические, медицинские и финансовые результаты — информация, не профессиональная консультация.

## Проверка после установки
1. Новый чат: «Какие навыки есть в Stefan Sense Bundle?» — модель должна перечислить основные навыки.
2. «Очеловечь: "В современном мире данный подход является ключевым."» — должен сработать `humanize-ru`.
3. «Найди навык для аудита SOC 2» — модель должна запустить поиск по библиотеке и найти `soc2-compliance` / `soc2-audit-prep`.
