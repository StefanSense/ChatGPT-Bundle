# Social media content

## 1. Inputs
Goal (awareness, leads, community, hiring), platform(s), audience, voice (examples of past posts are best), source material, CTA, constraints (no emojis, length).

## 2. Platform adaptation principles
Same idea, native form per platform — never paste one text everywhere.
- **LinkedIn**: strong first 2 lines (visible before "see more"), personal experience + lesson, short paragraphs, one question or CTA at the end; carousels for frameworks.
- **Telegram channel**: headline-like first line, compact paragraphs, useful links, formatting in moderation; series and polls work.
- **VK / Facebook**: community tone, longer stories allowed, image or video with the post.
- **Instagram**: visual first; caption hook in the first line; carousels for step-by-step; Reels for reach.
- **X / Threads**: one sharp idea per post; threads for breakdowns (hook post → numbered posts → summary).
- **TikTok / Reels / Shorts**: script with a hook in the first ~3 seconds, on-screen text, cuts, captions, CTA.
Character limits and algorithm details change: treat `references/platform-limits.md`, `references/platforms.md`, `references/x-algorithm.md` as dated source claims and verify when it matters.

## 3. Hooks
Curiosity, story, value ("How we…", «3 ошибки, которые…» only if there are really three), contrarian (with a real argument). No clickbait the post does not pay off.

## 4. Repurposing
Long piece → list its 5–10 standalone ideas → assign each to a platform/format → write → schedule. Keep facts and quotes exact; credit sources.

## 5. Content plan
3–5 pillars tied to expertise and audience; weekly mix (education / story / proof / engagement / offer); calendar table: date, platform, pillar, format, hook, CTA, status. Use ChatGPT scheduled tasks only if the user asks and the feature is available; publishing only through an authorized connector after explicit approval.

## 6. Quality rules
No AI tells (see `copywriting`), no invented stats or stories, no fake engagement bait, hashtags only where the platform uses them, accessibility (alt text, captions). Russian posts: apply `humanize-ru` hard bans.

## 7. Output
Ready-to-post texts per platform (with alt text / video script when relevant), 2 hook variants for the main post, and the calendar if requested.
