# Writing

Goal: a text the reader understands on the first pass and can act on. Clarity first, style second.

## 1. Brief (ask only what is missing, max 3 questions)
- **Reader**: who reads it, what they already know, what they want from it.
- **Purpose**: the one thing the reader should know, feel or do after reading.
- **Format and channel**: length, platform, register (formal / neutral / conversational), language.
- **Material**: facts, numbers, quotes, links, examples the user provides. Missing proof becomes `[NEED: …]`, never an invented fact.

If the request is clear enough, write first and list assumptions after the text.

## 2. Structure before sentences
1. Write the core message in one sentence. If you cannot, the brief is incomplete.
2. Pick a skeleton:
   - news / update: point → details → what it means → next step;
   - argument / opinion: claim → reasons with evidence → counter-argument → conclusion;
   - how-to: result → prerequisites → numbered steps → checks → troubleshooting;
   - story / case: situation → problem → action → result → lesson;
   - letter: purpose in the first two lines → context → request with deadline.
3. One idea per paragraph; the first sentence of each paragraph carries the idea.

## 3. Draft rules
- Concrete over abstract: names, numbers, examples, consequences.
- Short words and active voice; the subject does the action.
- Vary sentence length; avoid three parallel items unless there really are three.
- No filler openers ("In today's world", "It is important to note", «В современном мире», «Стоит отметить»).
- No staged contrasts ("not X but Y"), no one-line moral at the end, no dramatic fragments.
- Headings and bold only when the text is long enough to scan (> ~400 words) or the format needs them.
- Keep the user's terms, voice and facts. Do not add claims the user did not give.

## 4. Self-check before delivery
- Could a reader restate the core message after one read?
- Every number, name, date and quote comes from the user or a cited source.
- Cut 10–20 % of words that add nothing.
- Read for tells: apply `humanize-en` or `humanize-ru` rules quickly to your own draft (silently, no report).
- Length and format match the brief.

## 5. Output
The text itself first. Then, only if useful: 2–3 headline/subject options, assumptions made, `[NEED: …]` gaps.
