# Ad creative

## 1. Inputs
Platform and format, product and offer, audience and intent (cold / warm / retargeting), brand constraints, prohibited claims, landing page. If iterating: performance data (CSV/XLSX/paste) with impressions, CTR, CVR, CPA/ROAS per ad.

## 2. Modes
1. **From scratch**: angles → variations → spec check → upload-ready table.
2. **Iterate from data**: find winners and losers by the user's KPI (with enough volume — flag ads with too little data), extract patterns (angle, hook type, length, proof), generate new variations that extend winners and test one new angle.
3. **Grounded batch**: every concept cites its source (a real review, comment or winning ad). No grounding material → ask for it; do not invent.
4. **Strategy**: which concepts to make first, ranked by evidence, with a test plan.

## 3. Procedure
1. **Angles** (3–6): pain, outcome, objection, social proof, comparison, curiosity, offer/urgency (only real urgency).
2. **Per angle**: headlines and texts in several hook styles (question, number, statement, "how to", customer quote).
3. **Spec check**: platform limits change — read `references/platform-specs.md` as a starting point, verify current official limits when it matters, and count characters with code. Google RSA has used 30-character headlines and 90-character descriptions for years; still verify.
4. **Compliance**: no unsupported superlatives ("best", «№1») or health/finance promises; respect platform ad policies and local law (e.g. advertising labeling rules in the user's country); flag risky claims.
5. **Organize** as a table or CSV: platform, angle, headline, description/primary text, CTA, character counts, notes.

## 4. Writing standards
Specific benefits, the reader's words, one idea per ad, CTA matching the funnel stage. No AI tells (see `copywriting`). For visuals: describe the concept (scene, text overlay, format, safe zones) and, if image generation is available and requested, generate drafts; check that overlay text is legible and spelled correctly.

## 5. Output
Table of variations (+ CSV file on request), the logic per angle, what to test first and how to measure (one variable per test). For iterations: performance summary → patterns → new creative → recommendations.
