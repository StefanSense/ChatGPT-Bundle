# Editing and proofreading

Principle: improve what is there. The author's message, facts and voice are locked; every change needs a reason.

## 1. Choose the depth (default: ask nothing, infer from the request)
| Level | What changes | Typical request |
|---|---|---|
| **Proofread** | spelling, grammar, punctuation, typography, consistency | «вычитай», "check for errors" |
| **Line edit** | + wording, sentence clarity, rhythm, redundancy | «улучши», "polish" |
| **Structural edit** | + order of ideas, paragraphs, headings, missing parts | «переструктурируй», "make it flow" |
| **Copy edit (marketing)** | + the seven sweeps below | landing pages, ads, emails |

Never go deeper than asked. If deeper problems exist, list them instead of fixing them.

## 2. Procedure
1. Read the whole text once. Identify genre, register, reader, language variety (e.g. US/UK English, Russian typography «ёлочки», non-breaking spaces before dashes if the author uses them).
2. Lock facts: numbers, units, names, dates, quotes, links, legal wording, code.
3. Edit at the chosen level.
4. Compare with the original sentence by sentence: same claims, same certainty, same scope ("may" stays "may").
5. Final pass for consistency: terms, capitalization, numerals, list punctuation, quotation marks.

## 3. Seven sweeps (copy edit)
Run in order; after each sweep check that earlier ones still hold.
1. **Clarity** — can a newcomer understand each sentence? One idea per section.
2. **Voice and tone** — consistent formality and personality; read aloud.
3. **So what** — every feature is tied to a reader benefit.
4. **Prove it** — every claim has evidence; missing proof → `[NEED: proof]`.
5. **Specificity** — vague words replaced with concrete facts the author supplied.
6. **Emotion** — the reader's real stakes are visible, without hype.
7. **Zero risk** — objections and risks near the call to action are addressed.

## 4. Output
- Default: the edited text, then a short list of significant changes (max 7 bullets, grouped).
- If the user wants to see changes: a table `original → edit → reason`, or the text with changes marked **bold**/~~strikethrough~~.
- Flag, do not silently fix: factual doubts, legal/medical claims, possible plagiarism, inconsistent numbers.

## 5. Don'ts
- Don't "improve" by adding new facts, examples or opinions.
- Don't flatten a deliberate personal style into neutral corporate prose.
- Don't change terminology the author uses consistently.
- Don't edit quotations, names of laws, product names, code.
